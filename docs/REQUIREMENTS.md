# 要件定義

kobito-tools シリーズのクリップボード履歴アプリの要件です。Paste の代わりとして、それ以上に使えることを目指します。

アプリ名は **CorkClip**（コピーした物を、コルクボードにピンで留めるように取っておくクリップボード履歴）です。以前の名前は Pastephant で、そのときの履歴・設定・基準パスに残した物は、初めて起動・基準パスを開いたときに新しい名前のフォルダへ移します。

kobito シリーズの1つです。ほかのアプリとは `docs/kobito-spec/CONTRACTS.md` の約束だけでつながり、ほかのアプリの名前はこの文書にも書きません。

## 1. 前提

| 項目 | 決定 |
|---|---|
| 対応OS | macOS 13 以降（Apple Silicon / Intel のユニバーサルバイナリ） |
| 実装 | Swift ネイティブ（SwiftUI ＋ AppKit）。`build.sh` と `swiftc` でビルド（Xcode プロジェクトは作らない） |
| 同期 | しない。iCloud や他の端末との同期はなし |
| 保存 | 履歴はすべてこのMacの `~/Library/Application Support/CorkClip/` に保存（SQLite ＋ 生データはファイル）。クラウドに上がらず、Macごとに別の履歴になる（→ 6章） |
| 基準パス | 任意。指定すると、共有タグ（`.kobito-tools/Tags/tags.json`）と「カードに残す」（`.kobito-tools/CorkClip/`）に使う。履歴の保存には使わない |
| 画面 | 画面の右端から出てくる縦のリスト。右か左かは設定で切り替え（→ 3章） |
| ネットワーク | 使わない。LaTeX の描画もオフラインで行う |
| 配布 | シリーズ共通（公証なし、Releases で dmg・zip、`xattr` の案内） |

## 2. 必要な権限

| 権限 | 使う機能 | 無いとき |
|---|---|---|
| アクセシビリティ | ペースト（`⌘V` の送信）、ペーストスタック中の `⌘V` の検知 | 項目をクリップボードに戻すだけにし、ペーストはユーザーに任せる。初回に案内を出す |
| 画面収録 | 使わない（OCR はコピーされた画像にだけ行う） | — |

## 3. 画面

### 3.1 履歴パネル

```text
                                   ┌──────────────────────┐
                                   │ 🔍 検索…      ⇅  ⚙  │
                                   │──────────────────────│
                                   │ PowerPoint  #論文 図形 │ ← プレビュー（選んでいる行、
  （作業中のアプリ。                │  ┌────────────────┐  │    カーソルを当てている間はその行）
    フォーカスは移らない）          │  │  [図形の画像]   │  │    作業中は、その画面
                                   │  └────────────────┘  │    （タグ・編集・変換・まとめる・
                                   │ 09/28 14:05・コピー2回 │     数式・定型文・キーの一覧）
                                   │──────────────────────│
                                   │ 📌 ピン・定型文        │
                                   │   署名                 │
                                   │ 🕘 履歴               │
                                   │ ▶ 図形 3 個 PowerPoint │ ← 選択中
                                   │   \int_0^1 f(x)dx  数式│
                                   │──────────────────────│
                                   │ ⏎ 貼る ⇧⏎ プレーン …  │
                                   └──────────────────────┘
                                         画面の右端に張り付く
```

- グローバルショートカット（初期値 `⌥⌘V`、変更可能）で、設定した側の端からスライドして出てきます。もう一度押すか `Esc` を押す、またはパネルの外をクリックすると閉じます。
- **フォーカスを奪わない** `NSPanel`（`.nonactivatingPanel`）を使います。ペースト先のアプリはアクティブなまま、キー入力だけをパネルが受け取ります。
- 画面を広く使わないよう、**1つのパネルの上部をプレビュー、その下を一覧**にします。プレビューは枠（カード）で囲み、その下辺に貼り方の帯を付けて、一覧との境目をはっきりさせます。
- 見た目はコルクボードに見立てます（木の枠、コルクの地。粒の模様は画像を同梱せずに描く）。検索欄・見出し・キーの案内は細長い紙、プレビューは両端を画びょうで留めた紙にします。文字は小人の墨色、アクセントはシリーズの青みがかった灰色で、暗い画面にも対応します。一覧の1件は画びょうで留めたメモ用紙にし、左の帯で色分けします（コピー元のアプリ・種類・最初のタグ・なし。色はシリーズ共通のタグの色と同じハッシュでシリーズの色から選ぶ）。選んでいる紙は少し持ち上げ、画びょうはピン留めが赤、定型文が緑、ほかは真鍮色にします。
- パネルの内側の縁に、小人がしがみつき、ゆっくり揺れます（パネルの子ウィンドウでクリックは下へ通す。左端のときは反転。設定で隠せる）。
- 設定の画面でパネルの幅・出る側・プレビュー・色分け・小人を変えている間は、実物のパネルを画面の端に出したままにし、変えるたびにすぐ反映します（設定を閉じると隠れる）。作業の画面（タグ・編集・変換・まとめる・数式・定型文）は、プレビューの場所に出します。
- 出てくる側（右か左か）、幅、どのディスプレイに出すか（マウスのある画面 / メインの画面）、プレビューを出すかは設定で変えられます。
- 各行には種類のアイコンかサムネ、見出し（テキストの冒頭 / 定型文とピンの名前）、コピー元のアプリのアイコン、経過時間、タグを表示します。
- プレビューには中身（文字はスクロール・選択でき、画像は大きく、ファイルは場所）と、コピー元・日時・回数・大きさ・タグ・型の一覧を出します。`⌘Y`（検索が空なら `Space` も）で Quick Look も開けます。

### 3.2 キー操作

たくさんのショートカットを覚えなくても使えるよう、**貼るときのキーは4つ**にし、パネルの下にキーの名前（Enter・Shift など）と一緒に大きく出します。ほかのキーは、覚えた人が速く使うためのものです。

| キー | 動作 |
|---|---|
| `⏎` | そのまま貼る（`⇥` / `⇧⇥` で**貼り方**を選んだときは、その貼り方で貼る） |
| `⇧⏎` | 書式を除いて貼る |
| `⌃⏎` | 前回の貼り方で貼る（「そのまま」以外で最後に使った貼り方。設定のファイルに残し、案内に名前を出す） |
| `→`（`⌘K`） | パネルの上半分に**ほかの変換**、下半分にその項目に**できること**の一覧を開く |

- **貼り方の帯**：プレビューの下に、選んだ項目の中身に合う貼り方だけを並べます（文章なら改行を消す・句読点、表なら LaTeX・Markdown・CSV、ファイルならパス、画像なら画像の文字、数式なら LaTeX の式、保存した変換の組み合わせ）。選んだ貼り方で**実際に貼られる内容をプレビューに出し**、貼る前に確かめられるようにします。ほかのクリップボード管理アプリとの違いはここです。
- **→ の画面**：上のほかの変換は `↑↓` と `⏎` で選び、`⇥` で下のできることに移ります。できることは、その項目で使える操作だけを1文字のキー付きで並べます（`T` タグ・`P` ピン・`E` 編集・`M` まとめる・`L` 数式・`K` スタック・`S` カードに残す・`D` 削除）。`⌘` は押さずに、その文字だけで実行します。各行の右に `⌘` のショートカットを小さく出し、使ううちに覚えられるようにします。右クリックのメニューにも同じ物を出します。
- 一覧の画面の下には、上の4つのキーを大きく出します（行をクリックしても同じことをする）。作業の画面では、その画面で使うキーだけを細い帯に出します。

| 覚えると速いキー | 動作 |
|---|---|
| `↑` `↓` / `⌃N` `⌃P`（`⇧` で複数選択） | 選択を移動 |
| 文字の入力 | そのまま検索欄に入る |
| `⌘1`〜`⌘9` / `⌃1`〜`⌃9` | 上から N 番目を貼る / 保存した変換の組み合わせ N で貼る |
| `⌘⏎` / `⌥⏎` | コピーだけ / 改行を消して貼る |
| `⌘T` `⌘E` `⌘P` `⌥⌘↑↓` `⌘L` `⌘M` `⌘N` | タグ・編集・ピン・ピンの並べ替え・数式・まとめる・定型文 |
| `⌘S` / `⌘⇧N` / `⌥⌘⇧N` | カードに残す / 送る（送り先を選ぶ） / 最後に使った送り先へ送る |
| `⌘Y`（検索が空なら `Space`） / `⌘⌫` | Quick Look / 削除 |
| `⌘/` / `⌘,` / `Esc` | キーの一覧 / 設定 / 戻る・検索を消す・閉じる |

## 4. 機能要件

### F-01 履歴の取得

- `NSPasteboard.general.changeCount` を 0.3 秒ごとに見て、変わったら取得します。
- 1回のコピーに含まれる**全ての `NSPasteboardItem` の、全ての型（UTI）とデータ**を保存します。複数の項目があるコピー（Finder で複数のファイルを選んだときなど）も、その構成のまま保存します。
  - パワポの図形群、Excel のセル範囲、Keynote のオブジェクト、RTF/HTML の書式付きテキスト、画像、ファイル参照などが、元のアプリへ**元の形のまま**戻せることを受け入れ条件とします。
  - アプリ独自の型も捨てずに保存します。
- 一緒に記録する情報：コピーした日時、コピー元のアプリ（コピーされた瞬間の最前面のアプリの bundle ID と名前）、代表の種類、プレビュー用のテキストとサムネ。
- 代表の種類：`text` / `richText` / `image` / `file` / `url` / `color` / `office`（パワポなど独自の型が主）/ `formula`（F-06 で作ったもの）。
- **重複の扱い**：全ての型のデータから計算したハッシュが同じなら新しい項目を作らず、既存の項目を先頭に移して「コピーした回数」を増やします。
- 自分がクリップボードに書いたもの（ペーストのために戻したときなど）は、独自の型 `io.github.kobito-tools.corkclip.own` を付けておき、履歴に二重に入れないようにします。
- 1項目の上限を設定します（初期値 100MB）。超えた項目は、プレビューだけを残して生データは保存しません。一覧でもそれとわかるように表示します。

### F-02 取得しないもの（プライバシー）

- `org.nspasteboard.ConcealedType`、`org.nspasteboard.TransientType`、`org.nspasteboard.AutoGeneratedType` が付いたものは保存しません（1Password などのパスワード管理アプリ）。
- 除外するアプリの一覧（初期値：キーチェーンアクセス、主なパスワード管理アプリ）。
- メニューバーから「一時停止」できます（再開するまで、または指定した時間だけ）。

### F-03 ペースト

- 選んだ項目をクリップボードに書き戻し、アクセシビリティ経由で `⌘V` を送ります。パネルは先に閉じ、元のアプリにキーが届いてから送ります。
- 書き戻したあと、ペースト前のクリップボードに戻すかどうかは設定で選べます（初期値：戻さない）。
- **プレーンテキストで貼る**：`public.utf8-plain-text` だけを載せます。
- **改行を消して貼る**：F-07 の「改行を消す」と同じ処理です。

### F-04 タグ

- 1つの項目に複数のタグを付けられます。候補の出し方と新しいタグの作り方はシリーズ共通の `⌘T` と揃えます。
- タグは**シリーズ共通のタグ**を使います。基準パスを指定していれば `<基準パス>/.kobito-tools/Tags/tags.json` を正本とし、このMacのDBの `tags`・`tag_categories` 表はその写しです。同期の規則はシリーズ共通（約束 ⓪-2。`TagStore.swift`）です。
  - 基準パスを指定していないときは、このMacのDBだけでタグを管理します。後から指定すると、同期の規則で `tags.json` とまとめます。
  - タグは完全には削除せず、アーカイブだけにします（シリーズの規則）。
- パネル上部の絞り込みで、タグを選んで表示できます（複数選んだときは AND）。
- **コピー元のアプリで自動タグ付け**：「アプリ → タグ」の対応を設定しておくと、コピーした時点で付きます（例：Overleaf、TeXShop → `#latex`）。コピー元のアプリはブラウザのタブまでは見分けられないため、ブラウザの場合は URL を含むテキストの**ドメインで判定する**規則も選べます。

### F-05 検索と並べ替え

- 検索の対象：テキスト、OCR で読み取った文字（F-08）、タグ、コピー元のアプリ名、ファイル名、LaTeX の元の式。
- SQLite の FTS5 で全文検索します。日本語でも見つかるように、trigram トークナイザを使います。
- 絞り込みの書き方：`#タグ`、`type:image`、`app:PowerPoint`、`is:pinned`、`after:2026-09-01`。
- 並べ替え：最後に使った日時（初期値）/ コピーした日時 / 使った回数 / 種類 / コピー元のアプリ。

### F-06 LaTeX → 数式画像

- `⌘L` か、メニューバーから開く入力欄に LaTeX の式を書くと、その場でプレビューします。`⏎` で画像を作って貼ります。
- 選んだテキストの項目が LaTeX の式に見えるとき（`$...$`、`\[...\]`、`\frac` など）は、変換メニューからそのまま画像にできます。
- 描画には **KaTeX をアプリに同梱**し（MIT ライセンス）、WKWebView で描きます。KaTeX が対応していない命令は、エラーの場所を表示します。
- クリップボードに載せる型：**PDF（ベクター）＋ PNG（Retina 解像度）＋ TIFF**。
- オプション：文字色、文字の大きさ（pt）、背景（透明 / 白 / 任意の色）、インライン / ディスプレイ、余白。設定はよく使う組み合わせを「プリセット」として保存できます（例：「暗いスライド用（白文字）」）。
- **元の式を埋め込む**：PDF のメタデータ、PNG の `iTXt` チャンク、独自の型 `io.github.kobito-tools.corkclip.latex` の3か所に元の式とオプションを入れます。
  - 履歴の数式の項目から、元の式を開き直して直せます。
  - 作った画像がほかのアプリからコピーされて戻ってきたときも、埋め込まれた式を読み取り、`formula` として扱います。
- よく使う式やマクロ（`\newcommand`）は設定に登録でき、全ての式の前に付けて描画します。

### F-07 貼る前の変換メニュー

`Tab` で開きます。変換したものを貼るだけで、元の項目は変えません。

| 変換 | 内容 |
|---|---|
| 改行を消す | 日本語の行どうしはそのままつなぎ、英語の行どうしは半角スペースを入れる。行末のハイフネーションを直す（`inter-⏎national` → `international`。`e-⏎mail` のように元からハイフンがある語は、macOS の `NSSpellChecker` で判断。つないだ語が辞書にあればハイフンを消し、無ければ残す）。空行（段落の区切り）を残すかは設定で選べる |
| 句読点の変換 | `、。` ↔ `，．` |
| 全角・半角の統一 | 英数字と記号を半角に、カタカナを全角に（それぞれ選べる） |
| 空白を消す | 前後の空白、連続する空白、行末の空白 |
| 大文字・小文字 | 大文字 / 小文字 / 先頭だけ大文字 |
| 表の変換 | Excel などからコピーした表（TSV、または HTML の `<table>`）を、**LaTeX の `tabular`** / Markdown の表 / CSV に変換 |
| 引用 | 各行の先頭に `> ` を付ける |
| 箇条書き | 各行の先頭に `- ` / `・` / `1.` を付ける |
| 数式画像にする | F-06 へ |
| パスとして貼る | F-12 へ |

- 変換はいくつかを続けてかけられます（例：改行を消す → 句読点の変換）。よく使う組み合わせは名前を付けて保存し、ショートカットを割り当てられます。

### F-08 画像の文字認識（OCR）

- 画像の項目は、保存したあと裏で Vision フレームワーク（`VNRecognizeTextRequest`、日本語・英語）にかけ、読み取った文字を検索の対象にします。
- 変換メニューの「文字として貼る」で、読み取った文字をテキストとして貼れます。
- 処理が重いときは待ち行列に入れ、コピーの取得を止めないようにします。

### F-09 ピン留めと定型文（スニペット）

- 履歴の項目をピン留めすると、一覧の先頭の「ピン」の欄に固定され、自動で消える対象から外れます。
- 定型文は新しく作ることもできます。次の差し込みに対応します。

| 差し込み | 内容 |
|---|---|
| `{date}` `{date:yyyy/MM/dd}` | 今日の日付（書式を指定可） |
| `{time}` | 今の時刻 |
| `{clipboard}` | 今のクリップボードのテキスト |
| `{cursor}` | 貼ったあとのカーソルの位置（`←` を送って戻す） |

- ピンの並び順は `⌥⌘↑` `⌥⌘↓` で変えられます（一覧のドラッグは F-13 の「取り出す」に使うため）。

### F-10 貼る前に編集

- `⌘E` でその場で編集できる欄を開き、`⌘⏎` で貼ります。
- 編集したものは新しい項目として履歴に入ります（元の項目は残します）。

### F-11 複数の項目を1つにまとめる

- 複数選んで `⌘M` を押し、区切り（改行 / 空行 / 読点 / カンマ / 任意の文字列）を選ぶと、1つのテキストにして貼るか、新しい項目として保存します。
- 並びは選んだ順です。

### F-12 ファイルをパスとして貼る

- Finder でコピーしたファイルを、次のいずれかで貼れます：絶対パス / `~` を使ったパス / 指定した基準フォルダからの相対パス / ファイル名だけ / `file://` の URL。
- 複数のファイルの場合は改行でつなぎます。
- ファイルの項目は**パス（とブックマーク）を記録するだけ**で、中身はコピーしません。ファイルが消えた・移動したときは一覧で薄く表示します。

### F-13 ドラッグ＆ドロップで取り出す

- パネルの行をドラッグして、ほかのアプリにドロップできます。保存してある全ての型をドラッグに載せます。
- 複数選んでドラッグしたときは、文字を改行でつないだ物を載せます（1回のドラッグで渡せるのは1つの項目のため）。

### F-14 ペーストスタック（順番に貼る）

- グローバルショートカット（初期値 `⌃⌘C`）でスタックモードを始めます。始めると画面の端に小さな「スタック N 件」の表示が出ます。
- スタックモードの間にコピーしたものは、順番にスタックに積まれます（履歴にも入ります）。パネルから複数選んで「スタックに入れる」こともできます。
- スタックモードの間は、`⌘V` を押すたびに**積んだ順に1つずつ**貼られます。CGEventTap で `⌘V` を検知し、貼られたのを待ってから次の項目をクリップボードに載せます。
- 最後まで貼るか、もう一度ショートカットを押すと終わります。「逆の順番に貼る」も設定で選べます。

### F-15 消える期限

- 種類ごとに保存期間を設定できます（初期値：テキスト 無期限、画像 30日、office 30日、ファイル参照 90日）。
- 履歴の件数の上限と、生データの合計容量の上限（初期値 5GB）も設定できます。超えたら、古くてピン留め・タグのない物から消します。
- ピン留めしたもの、タグの付いたものは消しません（タグ付きも消すかは設定で選べます）。
- 設定画面に今の容量を表示し、「今すぐ整理」ボタンを置きます。

### F-16 送る（⑦ 受け渡し）

- `⇧⌘N`（`→` の `N`）で「送る…」の一覧を出します。送り先は、このMacの起動情報（④ `~/Library/Application Support/kobito-tools/apps/*.json`）の `receive` を集めて**実行時に作ります**。表示は「`name`：`label`」です。
- 並べるのは、`accepts` に、選んだ項目の中身（`text`・`image`・`file`）のどれかを含む口だけです。自分の口は並べません。
- 送り先は `1`〜`9` で選びます。最後に使った送り先は覚えておき、`⌥⇧⌘N` で一覧を出さずにそこへ送ります（今は使えなければ一覧を出す）。
- 送り方は ⑦ のとおりです。OS の一時フォルダの `kobito-share/`（権限 700）に `<UUID>.json`（権限 600）を書き、口の `url` の `{file}` をそのパス（URL エンコード）に置き換えて、送り先の起動情報の `command` の最後に足して起動します（シェルを通さない）。起動できなければ書いたファイルを消します。24時間より古いファイルは送るときに消します。
- 文字（数式は元の式）は `text`、画像は PNG にそろえて `images`、ファイルの項目はパスと名前を `files` に入れます。口が受け取れない種類は入れません。
- 送り先が1つも無いときは、「送り先のアプリがありません。kobito シリーズについては https://github.com/kobito-tools を参照してください」と表示します。

### F-17 カードに残す（③ カード）

- `⌘S`（`→` の `S`）で選んだ項目を、基準パスに残します。「このタグが付いたら自動で残す」という規則も設定できます。カードを使わない人のために、設定でこの機能を隠せます（操作の一覧からも消える）。
- 残した項目は、基準パスの CorkClip 自身の DB（`.kobito-tools/CorkClip/database/kept.sqlite3`、`schema/kept/`）に、残した日と中身の写し（時刻・コピー元・タグの行、文字・数式の元の式・ファイルのパス・画像の文字、タグID、画像）を記録します。履歴の項目が期限で消えても、残した物は消えません。複数のMacが同じ基準パスに残せるよう、このMacの履歴ではなく基準パスに置き、`lock.json`（`app: "corkclip"`、30秒ごとに更新、2分で期限切れ）で同時に書かないようにします。
- 画像は PNG にそろえて `.kobito-tools/CorkClip/uploads/` に保存します。カードには画像を入れません。
- 残すたびに（と、起動時・基準パスを変えたときに）、`<基準パス>/.kobito-tools/CorkClip/cards.jsonl` を**日ごとに1枚のカード**で書き直します（一時ファイルから置き換え）。

| 項目 | 値 |
|---|---|
| `kind` | 「クリップ」 |
| `id` | `clips-<YYYY-MM-DD>` |
| `title` | 「10月15日のクリップ」 |
| `date` | その日 |
| `tags` | その日に残したクリップのタグID（重複を除く） |
| `text` | その日に残したクリップの文字（OCR の文字を含む）を、2000 文字まで |
| `url` | `kobito://corkclip/day/<YYYY-MM-DD>` |
| `updated` | その日に最後に残した日時（時差付き） |

- 日付の区切りは、項目を**残した日**（このMacの日付）で判断します（コピーした日ではありません）。
- 残した項目には、このMacの履歴にも印（`exported_at`）を付け、二重に残さないようにします。`kept:<日付>` でその日に残した物を絞り込めます（以前の `exported:` も使えます）。
- 以前の版は、残した物を日ごとのメモとして別の形の DB（`database/corkclip.sqlite3` の `memos` 表）に書いていました。`kept.sqlite3` を初めて開いたときに、そのメモを文字とタグごと一度だけ写します（元のファイルは消しません）。

### F-18 URL での呼び出し

- URL スキーム `corkclip://` で、次の操作をアプリの外から呼べるようにします。ランチャーに登録すれば1キーで使えます。

| URL | 動作 |
|---|---|
| `corkclip://open` | 履歴パネルを開く |
| `corkclip://open?tag=論文` | タグで絞り込んで開く |
| `corkclip://latex` | LaTeX 入力を開く |
| `corkclip://stack/toggle` | ペーストスタックを始める / 終える |
| `corkclip://pause` | 取得を一時停止 / 再開 |

- kobito シリーズの約束（②・④）として、起動のたびに起動情報 `~/Library/Application Support/kobito-tools/apps/corkclip.json`（`{"app": "corkclip", "name": "CorkClip", "command": ["/usr/bin/open", "-b", "<バンドルID>"]}`）を書き出します。`embed` と `receive` は持ちません（ほかのアプリの中には表示されず、起動するアプリとして名乗る）。
- 次の `kobito://` の URL を受け付けます。一度受け付けた形は、作りを変えても受け付け続けます。

| URL | 動作 |
|---|---|
| `kobito://corkclip/day/<YYYY-MM-DD>` | パネルを開き、その日に残したクリップで絞り込む |
| `kobito://corkclip/open/<クリップID>` | パネルを開き、そのクリップを選ぶ |
| `kobito://corkclip/panel` | パネルを開く（知らない形も同じ） |
| `kobito://corkclip/snippet` | 新しい定型文の画面を開く |
| `kobito://corkclip/latex` | 数式画像の画面を開く |
| `kobito://corkclip/settings` | 設定を開く |

- 起動情報には、見せ方と操作（④「見せ方と操作」）も書きます。

| 項目 | 値 |
|---|---|
| `name_en` | `CorkClip` |
| `color` | `teal`（シリーズの配色のうち、まだ使われていない色。コルクに近い `orange` は別のアプリが使っているため） |
| `icon` | `glyph` は `📌`。`file` は `.app` の中の `Contents/Resources/kobito/icon.svg` の絶対パス（`build.sh` がリポジトリの `kobito/icon.svg` をそのまま入れる。256 KB を超えたらビルドを止める）。画像が無いときは `glyph` だけ |
| `kinds` | `[{"kind": "クリップ", "label_en": "Clip", "glyph": "📌", "dates": "record"}]`（カードの日付は「残した日」なので記録） |
| `actions` | 下の表。`id` は変えません |

| `id` | 表示名 | URL | `role` |
|---|---|---|---|
| `panel` | 履歴を開く | `kobito://corkclip/panel` | |
| `today` | 今日残したクリップを見る | `kobito://corkclip/day/{today}` | |
| `snippet` | 定型文を作る | `kobito://corkclip/snippet` | `new` |
| `latex` | 数式画像を作る | `kobito://corkclip/latex` | |
| `settings` | 設定を開く | `kobito://corkclip/settings` | `settings` |

- URL は「URL を開く」Apple Event（`kAEGetURL`）として届きます。`applicationWillFinishLaunching` で `NSAppleEventManager` に受け口を登録します（未起動から開かれたときは `didFinishLaunching` より前に届くため）。`kobito` スキームは Info.plist に登録しません（ほかのアプリ宛ての URL まで受け取ってしまうため）。自分宛て（`kobito://corkclip/…`）以外は無視します。

### F-19 メニューバーと設定

- メニューバーのアイコンから、パネルを開く、LaTeX 入力、一時停止、スタック、設定、終了を選べます。Dock には出しません（`LSUIElement`）。
- ログイン時に起動（`SMAppService`）。
- 設定の項目：ショートカット、パネルの出る側・幅・ディスプレイ、除外するアプリ、自動タグの規則、保存期間と容量、LaTeX のプリセットとマクロ、変換の組み合わせ、ペースト後にクリップボードを戻すか、基準パス。
- 基準パスの候補として、⑥ 基準パスの履歴（`~/Library/Application Support/kobito-tools/datasets.json`）にある「kobito シリーズで使っているフォルダ」を、最後に開いた順に示します（`.kobito-tools/dataset.json` が今もあるものだけ）。基準パスを開いたら、自分の1件（`app: "corkclip"`）を書き込みます。
- 「連携」の画面には、シリーズの紹介として「kobito シリーズについて（GitHub の kobito-tools を開く）」のリンクを1つだけ置きます。

## 5. 非機能要件

| 項目 | 目標 |
|---|---|
| パネルの表示 | ショートカットを押してから 100ms 以内に表示 |
| 検索 | 履歴 10万件で、1文字打つごとに 50ms 以内に結果を更新 |
| 取得 | コピーから 0.5 秒以内に履歴に入る（OCR やサムネ作りは後回し） |
| 待機中の負荷 | CPU 使用率 はほぼ 0%、メモリ 100MB 以下 |
| 起動 | ログイン時の起動で、ほかのアプリの邪魔をしない |
| データの安全 | このMacの履歴DBは WAL で保存（基準パスに置く、残したクリップのDBはシリーズと同じ DELETE モード）。生データは一時ファイルに書いてから名前を変えて置く。アプリが落ちても履歴が壊れない |
| 送信 | 外部への通信をしない |

## 6. 保存の設計

```text
~/Library/Application Support/CorkClip/
├── database/history.sqlite3   項目・型の一覧・タグの写し・全文検索
├── blobs/ab/abcdef….bin       生データ（中身のハッシュ名。同じデータは1つだけ）
├── thumbs/<項目ID>.png        一覧用のサムネ
└── settings.json              このMacの設定（ショートカット、パネル、保存期間、基準パスなど）
```

基準パスを指定したときに使う場所（シリーズ共通。`docs/kobito-spec/CONTRACTS.md`）：

```text
<基準パス>/.kobito-tools/
├── dataset.json                    読むだけ（無ければ ID を尋ねて作る）
├── Tags/tags.json                  共有タグ（F-04）
└── CorkClip/                    カードに残す（F-17）
    ├── lock.json
    ├── database/kept.sqlite3       残したクリップの写し（schema/kept/）
    ├── uploads/                    残した画像（PNG）
    └── cards.jsonl                 ③ 日ごとのカード
```

主な表（詳しくは `schema/` で決めます）：

| 表 | 内容 |
|---|---|
| `clips` | ID、代表の種類、プレビューのテキスト、コピー元のアプリ、コピーした日時、最後に使った日時、使った回数、ピン、並び順、全体のハッシュ、カードに残した日時 |
| `clip_representations` | どのクリップの何番目の `NSPasteboardItem` の何番目の型（UTI）か、生データのハッシュ（`blobs/` の名前）、大きさ |
| `tag_categories`, `tags` | 共有タグの写し（ID は文字列。シリーズ共通の形） |
| `clip_tags` | 項目とタグの対応と、その付け方（手動 / 自動） |
| `snippets` | 定型文 |
| `clip_search` | FTS5（テキスト、OCR の文字、LaTeX の式、ファイル名、アプリ名） |

- 生データは中身のハッシュを名前にしているので、同じ画像を何回コピーしても容量は1つ分です。使われなくなった生データは、整理のときに消します。
- 履歴は基準パスに置きません。基準パスに書くのは F-17 の「残す」を選んだ物だけです。

## 8. ほかのアプリとのつながり

ほかのアプリとは約束（`docs/kobito-spec/CONTRACTS.md`）だけでつながるので、ほかのアプリ側に CorkClip のための変更は要りません。送り先・カードの表示・URL の開き方は、すべて約束の形で決まります。
